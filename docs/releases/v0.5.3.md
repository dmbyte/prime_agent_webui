# Prime Agent WebUI v0.5.3

This patch release keeps the OpenShell-based DGX Spark runtime and local model
stack: Nemotron 3.5 Lightning as the default local model and Qwen 3.8
Flash-Next as the local specialist.

## Highlights

- Fixes the OpenShell task launcher so sandbox creation cannot consume the
  initial Prime RPC messages intended for the actual task. This resolves the
  WebUI staying at **Starting Prime** after a message is sent.
- Lowers the Nemotron 3.5 Lightning vLLM GPU-memory target to `0.38` so it can
  start cleanly while Qwen 3.8 Flash-Next remains resident.
- Keeps the explicit Nemotron 4 GiB KV-cache cap and three-token DSpark
  speculative configuration.
- Keeps the visible boxed `...` sidebar chat actions and active-chat
  **Add to project** / **Move project** button from v0.5.1/v0.5.2.

## Upgrade notes

Use `v0.5.3` for fresh clones and manual upgrades. On DGX Spark, update the
WebUI/runtime helper and restart Nemotron if it was still using the older
`GPU_MEMORY_UTILIZATION=0.48` setting.

Qwen 3.8 is still the only shipped local Qwen runtime for this release.
