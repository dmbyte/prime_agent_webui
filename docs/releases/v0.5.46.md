# Prime Agent WebUI v0.5.46

This patch keeps the used and free RAM amounts introduced in v0.5.45 fully
visible in the narrow expanded memory graph. The on-card suffix is shortened
to `G` (GiB); the accessible label retains the full GiB wording. A live Chrome
check confirmed both lines fit on the Spark dashboard.

The percentage, one-second polling, and Linux `MemAvailable` definition of
free RAM are unchanged.
