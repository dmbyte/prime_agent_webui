# Prime Agent WebUI v0.5.31

v0.5.31 fixes repeated BMC browser launches from Prime's persistent IPython
kernel. The Playwright worker remains isolated in a clean subprocess, while the
parent now uses thread-backed standard-I/O instead of asyncio's subprocess child
watcher. This avoids a live-kernel condition where the first browser opened and
closed successfully but a subsequent worker stopped delivering its startup
reply.

The browser package is now `prime-bmc-headless-browser` 1.1.1. All six
OpenShell image identities are repinned from the installer's exact normalized
three-skill build context.

Validation includes the managed-skill test suite and three consecutive browser
open/close cycles from IPython in the candidate network-operations image. Final
deployment validation repeats the workflow through Prime and OpenShell.
