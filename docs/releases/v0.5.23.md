# Prime Agent WebUI v0.5.23

This release adds a reproducible, protected global skill installation for the
DGX Spark OpenShell deployment.

- Pins the official NVIDIA skills repository at commit
  `fd9f1466ff8a39178e488981e8b5118709392949` and validates all 366 skill trees.
- Stores the unchanged catalog in protected Prime state and exposes it through a
  lazy router, avoiding roughly 13,000 tokens of per-task catalog descriptions.
- Packages the Prime-created BMC browser as a working Prime Python skill using
  the immutable network-operations Chromium instead of task-time OS installs.
- Replaces the placeholder HPE-only BMC helper with portable Redfish discovery
  and working `ipmitool` calls.
- Requires explicit confirmation in code for all BMC power mutations, keeps
  credentials runtime-only, and retains prior managed installs in recovery.
- Makes the two BMC adapters part of the normal OpenShell installer and documents
  the one-command NVIDIA catalog follow-on for a reproducible deployment.

`scripts/validate-release.sh` includes the managed-skill tests in addition to
the full dashboard suite. Use `v0.5.23` for fresh installation or the WebUI
software updater for an existing Spark.
