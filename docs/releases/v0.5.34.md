# Prime Agent WebUI v0.5.34

v0.5.34 carries the verified v0.5.33 BMC browser repair and closes the release
activation gap found during its deployment.

The in-app Prime WebUI updater now invokes the same reviewed OpenShell installer
used for a clean deployment whenever OpenShell and Docker are present. That
installer rebuilds all six normalized profiles, verifies every image against
the release manifest, installs the managed skills and runner policy, and only
then allows the update to report success. Generic non-OpenShell installations
continue to update without the Spark image step.

The installed v0.5.33 image was independently verified before this updater
change: a genuine Prime task launched `prime-bmc-headless-browser` 1.2.0 in the
final network-operations image, became ready in 0.46 seconds, navigated
read-only to the BMC with HTTP 200, and closed normally.
