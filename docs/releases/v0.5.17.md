# Prime Agent WebUI v0.5.17

This release supersedes v0.5.15 and v0.5.16 with deterministic OpenShell image
verification for clean installations.

## Changes

- Retains the persistent skill registry, writable package caches, project
  virtual environments, pip support, Chromium, ipmitool, and corrected
  idempotent NVIDIA package installation.
- Normalizes a temporary copy of the reviewed Docker build context before every
  profile build.
- Retains exact approved image-ID verification and the protected runtime
  manifest.
- Continues to restrict the runner to installer-approved profile names, tags,
  and exact image builds; tasks remain non-root with read-only system paths.

## Why

Docker image IDs include build-context metadata such as copied-file timestamps.
Two clean checkouts therefore differed even though their contents matched.
Normalizing the copied context removes that nondeterminism without weakening
the existing exact-ID review gate.

## Validation

`scripts/validate-release.sh` passes with 104 tests. v0.5.17 is the supported
release for fresh installs and upgrades.
