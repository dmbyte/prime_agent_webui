# Prime Agent WebUI v0.5.26

This release makes the lazy BMC browser work inside the enforced OpenShell
sandbox rather than only in a conventional Docker container.

- Gives each Chromium instance a private ephemeral HOME, config, and cache tree
  under OpenShell's writable `/tmp` path, fixing crashpad initialization against
  the read-only image home.
- Disables Chromium GPU and zygote subprocesses, which are incompatible with the
  task sandbox's process restrictions and unnecessary for headless BMC pages.
- Cleans up browser runtime state after normal exit and failed startup.
- Validates navigation and page interaction inside a real policy-enforced
  OpenShell sandbox using the production mounts and network-operations image.

Use `v0.5.26` for fresh installation or the WebUI software updater for an
existing Spark deployment.
