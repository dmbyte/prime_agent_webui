# Prime Agent WebUI v0.5.22

This release completes the governed skill and tool workflow introduced in
v0.5.21 by giving administrators direct access to the submitted source archive
before approval.

It includes user requests, administrator approval and lifecycle controls,
project skill selection, safe persistent extraction, source SHA-256 display,
downloadable source review, sandbox profile inventory, and image-required
handling for operating-system tools. Approval never invokes a package manager
or grants root inside a task.

`scripts/validate-release.sh` passes with 109 tests. Use `v0.5.22` for fresh
installs and upgrades; it supersedes v0.5.21.
