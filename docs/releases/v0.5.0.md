# Prime Agent WebUI v0.5.0

This release moves the DGX Spark deployment to the OpenShell-based runtime and
documents the reproducible local model stack: Nemotron 3.5 Lightning as the
default model and Qwen 3.8 Flash-Next as the local specialist.

## Highlights

- Runs Prime WebUI tasks inside NVIDIA OpenShell sandboxes through the local
  Docker driver.
- Ships a self-contained OpenShell installer that provisions `prime-runner`,
  the model gateway, the runner broker, protected per-user state, Docker
  volumes, and the six approved task images.
- Removes the superseded task-runtime activation path from the release source
  and docs.
- Removes the superseded prior Qwen service from the release source and docs.
- Adds the Qwen 3.8 Flash-Next llama.cpp service with lazy direct NVMe reads,
  Q8 K/V cache, multimodal projector support, and shared-Q8 MTP draft head.
- Keeps Nemotron 3.5 Lightning as the default Spark model with three-token
  speculative draft configuration.
- Adds account-scoped Projects in the sidebar with shared instructions,
  uploaded sources, inherited defaults for conversation controls, and promotion
  of existing chats into new or existing projects.
- Moves conversation controls below the conversation header and persists them
  for each chat unless changed.
- Adds collapsible Projects, Chats, Settings, and Admin groups.
- Adds OpenShell to the Settings software-update section.

## Upgrade notes

Use `v0.5.0` for fresh clones and manual upgrades. On DGX Spark, install and
verify the local models first, then run `deploy/spark/openshell/install.sh` and
`deploy/spark/prime/validate.sh`.

Qwen 3.8 is the only shipped local Qwen runtime for this release.
