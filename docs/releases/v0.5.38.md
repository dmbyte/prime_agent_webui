# Prime Agent WebUI v0.5.38

v0.5.38 fixes a false `task broker exited` failure that could appear after a
Prime/OpenShell task had otherwise completed. The privileged launcher previously
read its control stream through Python's buffered stdin from a daemon thread.
When Prime exited while that thread was blocked, interpreter finalization could
fail to acquire the buffered-reader lock, abort with signal 6, and make the
broker report a runtime failure.

The launcher now forwards control input with unbuffered file-descriptor reads,
which do not hold Python's buffered-I/O lock during shutdown. A regression test
forbids the old buffered read.

The repeated OpenShell activation path also treats legacy workspace copies as
migrations: `--ignore-existing` prevents old host/runtime workspaces from
overwriting the current host-visible task workspace or reintroducing a stale
managed policy on every WebUI update.
