# Prime Agent WebUI v0.5.6

This patch release makes submitted prompts durable when an OpenShell-backed task
fails before Prime can create its own conversation transcript.

## Highlights

- Stores the accepted user prompt in the WebUI task record as soon as
  `/api/tasks/start` accepts the request.
- If a task fails, times out, or is stopped before Prime creates a conversation,
  the WebUI now creates a recovered conversation containing the submitted user
  prompt and the runtime failure notice.
- Keeps the submitted prompt visible in the browser after a failed task even if
  recovery has not yet produced a conversation row.
- Preserves project, file, routing, model, effort, and task-policy metadata on
  recovered failed-task conversations.
- Retains the OpenShell FIFO relay and sandbox cleanup fixes from v0.5.5.

## Upgrade notes

Use `v0.5.6` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
update path so the live dashboard API and browser assets match this tag.

This release does not change the local model stack. Nemotron 3.5 Lightning
remains the default local model, and Qwen 3.8 Flash-Next remains the shipped
local Qwen runtime.
