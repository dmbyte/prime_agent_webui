# Prime Agent WebUI v0.5.28

This release makes stalled OpenShell tasks inspectable while they are running.

- The conversation trace reports startup stages and how long Prime has produced
  no output, instead of leaving an uninformative “Starting Prime” indication.
- Right-click a task trace or choose **Complete output…** to view its full
  redacted runtime output, updated every three seconds. The owner can download
  the persisted log before or after the task exits.
- Submitted prompts and live progress remain visible when the saved
  conversation transcript is temporarily unavailable.
- Frequent repeated tool/reasoning updates are coalesced in the short activity
  preview; the complete safe output is still retained.

Credential-shaped values and private reasoning remain masked. The runtime's
262 KiB per-event safety limit still applies. An OpenShell task that stops
producing output may require waiting for its configured task timeout or stopping
it manually; this release exposes the stall but does not change tool behavior.
