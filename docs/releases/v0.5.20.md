# Prime Agent WebUI v0.5.20

This release completes the OpenShell skill/tool installer repair and supersedes
v0.5.15–v0.5.19 for installation.

It retains persistent skills and task dependencies, the reviewed expanded tool
profiles, idempotent OpenShell package handling, deterministic exact image-ID
verification, and explicit gateway directory creation. The volume provisioner
now verifies protected prime-runner storage through the required administrative
boundary instead of misreporting mode-0700 gateway directories as missing.

`scripts/validate-release.sh` passes with 104 tests. Use `v0.5.20` for fresh
installs and upgrades.
