# Prime Agent WebUI v0.5.9

This release moves the default OpenShell task workspace onto the visible host
filesystem under the WebUI owner's home directory.

## Changes

- Changed the OpenShell task workspace backing `/project` from
  `/var/lib/prime-runner/users/USER/workspace` to
  `~/prime-agent/tasks/USER/`.
- Kept protected Prime state, sessions, credentials, and project sources under
  `/var/lib/prime-runner/users/USER/`.
- Updated the OpenShell installer and WebUI updater to create
  `~/prime-agent/tasks`, grant only the runner/WebUI ACLs required for task
  work, and refresh the `prime-USER-workspace` Docker bind volume.
- Added migration handling so existing files from the old runner workspace and
  `~/prime-dgx-agent` are copied into the new home-backed task folder.
- Updated the `prime-runner-broker` service boundary to allow the controlled
  `~/prime-agent` workspace while still keeping arbitrary `/home` path mounts
  out of the task-policy picker.

## Validation

`scripts/validate-release.sh` passed with 97 tests, including
coverage for the separate host workspace root, refreshed broker unit, and
home-backed Docker volume provisioning.

## Upgrade

Use `v0.5.9` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
