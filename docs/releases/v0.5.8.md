# Prime Agent WebUI v0.5.8

This patch release repairs OpenShell conversation resume after a sandbox worker
has failed.

## Changes

- Isolated every WebUI OpenShell task behind a per-task Prime daemon socket such
  as `/tmp/prime-daemon-<task>.sock`. This avoids reusing stale default daemon
  worker records from earlier ephemeral OpenShell sandboxes.
- Preserved normal conversation resume behavior without deleting Prime's
  conservative failed-worker recovery state.
- Wrote the final task status back into saved task metadata for tasks attached
  to existing conversations, so a failed/completed/stopped task no longer leaves
  its saved row stuck as running.
- Confirmed the failed `resume` task prompt was already retained in the task
  metadata; this release hardens future task recovery and status display.

## Included from recent patch releases

- v0.5.7 model-aware task traces render inside the conversation stream and
  collapse after completion.
- v0.5.6 prompt persistence and failed pre-transcript task recovery.
- v0.5.5 OpenShell task-start repair through the sandbox FIFO relay.

## Validation

`scripts/validate-release.sh` passed with 91 tests, including OpenShell
per-task daemon socket coverage and saved final task-status coverage.

## Upgrade

Use `v0.5.8` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
