# Prime Agent WebUI v0.5.12

This release adds persistent, scoped security approval so trusted chats and
projects no longer repeat the same confirmations on every message.

## Changes

- Adds **Security prompts** to the conversation toolbar and project defaults.
- Adds **Always allow for this chat** and **Always allow for this project**.
- Inherits the project setting into new chats while preserving independent chat
  overrides.
- Requires the complete requested security policy to match an owner-scoped saved
  policy before prompts are suppressed.
- Keeps role restrictions, OpenShell isolation, resource limits, and read-only
  host-path enforcement unchanged.
- New standalone chats still confirm their first task before saving the choice.

## Validation

`scripts/validate-release.sh` passed with 101 tests.

## Upgrade

Use `v0.5.12` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
