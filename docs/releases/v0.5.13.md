# Prime Agent WebUI v0.5.13

This release turns the compact Spark statistics at the top of the sidebar into
live visual telemetry.

## Changes

- Adds sparklines for CPU, GPU, memory, power, CPU temperature, GPU temperature,
  and system temperature.
- Keeps a rolling 60-second history in the browser without storing telemetry on
  the server.
- Displays the current value in large translucent type over each graph.
- Expands a statistic on mouse hover or keyboard focus to show a larger live
  graph and value.
- Refreshes the live telemetry endpoint every second.

## Validation

`scripts/validate-release.sh` passed with 102 tests.

## Upgrade

Use `v0.5.13` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
