# Prime Agent WebUI v0.5.30

v0.5.30 supersedes v0.5.29 with image IDs produced from the installer's exact
three-package managed-skill context. The v0.5.29 activation gate correctly
rejected its mismatched pre-release image manifest before installation.

The functional change remains the verified BMC browser fix:

- Playwright and Chromium run in a clean per-browser subprocess behind the
  existing asynchronous `BMCBrowser` API.
- Private JSON-lines pipes carry operations; every step is bounded, worker
  errors are retained, and an unresponsive worker is terminated.
- Existing OpenShell confinement, ephemeral browser state, screenshot path
  limits, runtime-only credentials, and confirmed state-changing clicks remain.
- All six reproducible images are pinned from the exact production installer
  build context.

A genuine Prime task completed browser entry, page creation, and cleanup in
11.8 seconds where the prior in-kernel adapter timed out at `newPage`.
