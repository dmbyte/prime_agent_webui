# Prime Agent WebUI v0.5.19

This release completes the OpenShell skill/tool installer repair and supersedes
v0.5.15–v0.5.18 for installation.

It includes persistent skill registration, writable package caches and project
virtual environments, pip in all profiles, Chromium/ipmitool in the guarded
network profile, corrected idempotent OpenShell package installation, and
deterministic exact image-ID verification. It additionally creates every
per-user gateway directory before Docker volume provisioning, removing an
assumption about pre-existing runtime-generated state.

`scripts/validate-release.sh` passes with 104 tests. Use `v0.5.19` for fresh
installs and upgrades.
