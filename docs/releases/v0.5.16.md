# Prime Agent WebUI v0.5.16

This release supersedes v0.5.15 with a corrected, idempotent NVIDIA OpenShell
package installation path.

## Changes

- Retains the persistent skill registry, writable package caches, project
  virtual environments, pip support, Chromium, ipmitool, rebuilt profile
  images, and documentation introduced in v0.5.15.
- Corrects NVIDIA's ARM64 package asset name to
  `openshell_0.0.116-1_arm64.deb` while retaining its published SHA256.
- Skips the package download when the pinned OpenShell version is already
  installed, allowing repeat installations without unnecessary network or
  package-manager work.

## Validation

`scripts/validate-release.sh` passes with 104 tests. The installed Spark runtime
reports OpenShell 0.0.116 and remained healthy after the failed v0.5.15 download
attempt, which stopped before image or service replacement.

## Upgrade

Use `v0.5.16` for fresh clones and upgrades. Do not use v0.5.15 for a fresh
OpenShell install.
