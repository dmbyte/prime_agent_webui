# Prime Agent WebUI v0.5.5

This patch release fixes OpenShell task startup and cleanup in the DGX Spark
WebUI runtime. It keeps the local model stack unchanged: Nemotron 3.5 Lightning
as the default local model and Qwen 3.8 Flash-Next as the local specialist.

## Highlights

- Installs the full privileged runner helper set during WebUI updates, including
  `task_common.py`, `openshell_runner.py`, `model_gateway.py`,
  `runner_broker.py`, the runner launcher, and the runner client.
- Fixes the OpenShell 0.0.116 stdin behavior by relaying Prime RPC input through
  a sandbox FIFO, so tasks progress past **Starting Prime** without waiting for
  stdin EOF.
- Terminates the per-task launcher when the dashboard client disconnects after
  `agent_end`, allowing the launcher to delete the completed OpenShell sandbox.
- Reports OpenShell runtime failures with current OpenShell terminology instead
  of the retired rootless-Podman wording.
- Shows `prime-model-gateway` and `prime-runner-broker` as system services in
  Admin status, while retaining user-service checks for the dashboard, terminal,
  OpenShell gateway, and model servers.
- Moves stale per-user `prime-model-gateway.service` and
  `prime-runner-broker.service` files into a recovery folder during OpenShell
  installation instead of leaving obsolete rootless unit labels behind.

## Upgrade notes

Use `v0.5.5` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
update path so both the dashboard files and privileged runner helper files match
this tag. Existing model services do not need to restart.

Qwen 3.8 is still the only shipped local Qwen runtime for this release.
