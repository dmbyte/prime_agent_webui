# Prime Agent WebUI v0.5.40

v0.5.40 fixes Codex OAuth credential rotation in the OpenShell model gateway.
The update path previously copied the host credential over the gateway copy on
every activation. If the gateway had already rotated its one-use refresh token,
a later update could restore the consumed token and every Codex request would
fail with an opaque HTTP 502.

The installer now compares credential expiry times and only installs a strictly
newer host credential. It will not overwrite an equal or newer gateway copy.
The gateway recognizes OpenAI's `refresh_token_reused` response, records a
sanitized diagnostic, and reports that `/login` is required without exposing
tokens or upstream response details.

Explicit slash routing is also authoritative. The first `/qwen`, `/nemotron`,
`/codex`, or `/chatgpt` directive now wins even when later prose mentions a
different model, making an explicit local fallback reliable.
