# Prime Agent WebUI v0.5.36

v0.5.36 aligns the WebUI task runtime with the host by upgrading all six
immutable OpenShell images from Prime Agent 0.8.0 to 0.9.5. The official
release artifact is pinned by its published SHA-256 checksum, and each profile
is pinned by its exact locally reproduced image ID.

The managed workspace policy now delegates to Qwen with Prime 0.9.5's Python
API and exact selector:

```python
await rlm.spawn(
    "<focused task>",
    name="<unique-name>",
    model="spark-qwen/qwen3.8-flash-next",
)
```

It also makes the execution boundary explicit: `rlm.spawn`,
`rlm.list_subagents`, and `agent_message.send` run inside `ipython`; they are
not model tool names. Omitting the child model inherits Nemotron. Install and
update now refresh an older managed policy with a timestamped backup while
leaving an unrelated custom `AGENTS.md` untouched.
