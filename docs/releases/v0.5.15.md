# Prime Agent WebUI v0.5.15

This release makes Prime skill registration and task-local dependency
installation work consistently inside the OpenShell runtime.

## Changes

- Registers skills persistently under `/home/prime/.prime/agent/skills`.
- Links the common `/project/.prime/agent/skills` compatibility path to the
  persistent registry and recoverably migrates workspace-only skills.
- Adds writable persistent caches for uv, pip, npm, and Playwright.
- Adds `/project/.venv/bin` and persistent npm user tools to task `PATH`.
- Includes pip in every task profile.
- Includes Chromium and ipmitool in the guarded network-operations profile.
- Fixes the OpenShell installer to build the tracked `Containerfile`
  explicitly.
- Pins all six rebuilt ARM64 profile images by immutable image ID.
- Documents the supported per-project Python installation workflow and the
  requirement to select Internet egress for downloads.

## Security

Tasks remain non-root, `/usr` remains read-only, and system packages remain an
image-build concern. The change adds writable locations only beneath the
existing per-user Prime state and task workspace mounts.

## Validation

`scripts/validate-release.sh` passes with 104 tests. All six ARM64 images were
built on the DGX Spark and their exact IDs were recorded in the image manifest.

## Upgrade

Use `v0.5.15` for fresh clones and manual upgrades. The Spark OpenShell
installer rebuilds and verifies the six profiles, prepares the persistent tool
directories, and refreshes the runtime services.
