# Prime Agent WebUI v0.5.29

This release fixes BMC browser page creation from Prime's persistent IPython
tool kernel.

- Moves Playwright and Chromium into a clean, per-browser subprocess while
  preserving the skill's async `BMCBrowser` API.
- Uses a private JSON-lines pipe rather than command-line arguments for browser
  operations and runtime values.
- Bounds every browser operation, captures child-process diagnostics, and
  force-stops a worker that does not answer.
- Preserves the network-operations-only image, ephemeral Chromium HOME/XDG
  state, workspace-only screenshots, and explicit confirmation for persistent
  BMC changes.
- Re-pins all six reproducible OpenShell images.

Validation included a genuine Prime task in the network-operations profile.
The same probe that previously timed out at `BrowserContext.new_page()` printed
browser-enter, page-ready, and browser-closed stages and completed in 11.8
seconds. No BMC system was contacted during the test.
