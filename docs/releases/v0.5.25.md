# Prime Agent WebUI v0.5.25

This release makes the lazy managed-skill images reproducible after local test
or import runs.

- Preserves v0.5.24's lazy BMC/browser behavior and immutable-kernel modules.
- Excludes generated Python bytecode and `__pycache__` directories from the
  normalized Docker build context.
- Re-pins all six OpenShell task-image IDs from the clean source-only context.
- Validates managed imports in every profile and a real Chromium launch in the
  `network-operations` profile.

Use `v0.5.25` for fresh installation or the WebUI software updater for an
existing Spark deployment.
