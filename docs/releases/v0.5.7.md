# Prime Agent WebUI v0.5.7

This release moves live task progress out of the chat-title status area and into
the conversation stream.

## Changes

- Added a model-aware task trace card in the active conversation. It shows safe
  progress lines such as `prime-qwen: using tool`, `prime-codex: reasoning in
  progress`, or `prime-nemotron: drafting response`, based on the active route.
- Kept task trace cards open while a task is running, then collapsed them after
  the result or failure is returned so the workspace stays readable.
- Preserved reviewability: completed task traces remain in the stream as a
  collapsible item.
- Stopped using the chat title subtitle for detailed live progress. The subtitle
  now stays at the project/conversation level while live progress appears in the
  chat body.
- Continued to avoid exposing private chain-of-thought. Reasoning parts are
  represented only as safe status text.

## Included from recent patch releases

- v0.5.6 prompt persistence and failed-task recovery: accepted prompts are saved
  immediately, and failed pre-transcript tasks can recover into a normal
  conversation with the submitted prompt and failure notice.
- v0.5.5 OpenShell task-start repair: Prime RPC input is relayed through the
  sandbox FIFO and completed task sandboxes are cleaned up.

## Validation

`scripts/validate-release.sh` passed with 90 tests, including static UI coverage
for visible project actions, failed-prompt retention, and the collapsible
model-aware task trace.

## Upgrade

Use `v0.5.7` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
