# Prime Agent WebUI v0.5.21

This release adds governed skill and tool management to the OpenShell WebUI.

- Users can submit personal or project-scoped skill ZIPs with declared access,
  dependencies, and system-tool requirements.
- Administrators receive a collapsible review queue with source hashes,
  dependency and permission previews, approval, denial, enable/disable, and
  recoverable removal controls.
- Approved instruction skills are safely extracted into the requesting user's
  persistent host-visible workspace registry. Archive traversal and links are
  rejected, extraction is bounded, and existing installs move to recovery.
- Project settings can select approved skills; the selection is included in
  shared project context for new and existing chats.
- System-tool requests require a reviewed immutable sandbox-image change. The
  approval path never invokes package managers, sudo, or root inside a task.
- The Admin inventory documents the tools included in each shipped task profile.

`scripts/validate-release.sh` passes with 109 tests. Use `v0.5.21` for fresh
installs and upgrades.
