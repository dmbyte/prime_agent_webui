# Prime Agent WebUI v0.5.27

This release makes v0.5.26's OpenShell-compatible BMC browser images exactly
reproducible across checkouts with different host ACLs.

- Preserves the verified private Chromium runtime directory and headless
  GPU/zygote restrictions from v0.5.26.
- Normalizes temporary Docker build-context directories to mode 0755 and source
  files to 0644 before applying the entrypoint's executable mode.
- Prevents host checkout group-write ACLs from changing reviewed image IDs.
- Re-pins all six task images from the fully normalized context.

Use `v0.5.27` for fresh installation or the WebUI software updater for an
existing Spark deployment.
