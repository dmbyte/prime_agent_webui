# Prime Agent WebUI v0.5.10

This patch release fixes the v0.5.9 workspace-volume migration helper.

## Changes

- Corrected the OpenShell Docker volume provisioning helper so an already-correct
  bind volume returns success instead of stopping the updater.
- Retains the v0.5.9 workspace layout: `/project` inside OpenShell maps to
  `~/prime-agent/tasks/USER/` on the host, while Prime state remains protected
  under `/var/lib/prime-runner/users/USER/prime`.

## Validation

`scripts/validate-release.sh` passed with 97 tests.

## Upgrade

Use `v0.5.10` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
