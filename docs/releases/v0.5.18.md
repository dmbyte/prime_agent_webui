# Prime Agent WebUI v0.5.18

This release completes the OpenShell skill/tool repair and supersedes
v0.5.15–v0.5.17 for installation.

## Changes

- Persists skills in Prime's real registry and recoverably migrates
  workspace-only skills.
- Provides writable persistent caches for uv, pip, npm, and Playwright plus a
  project virtual-environment path.
- Adds pip to every profile and Chromium/ipmitool to network-operations.
- Corrects and makes the pinned NVIDIA OpenShell package install idempotent.
- Normalizes timestamps and modes in a temporary Docker build context while
  retaining exact approved image-ID verification.

## Validation

All six normalized ARM64 profile builds reproduce the approved IDs.
`scripts/validate-release.sh` passes with 104 tests.

## Upgrade

Use `v0.5.18` for fresh installs and upgrades.
