# Prime Agent WebUI v0.5.35

v0.5.35 expands the co-resident Qwen 3.8 Flash-Next context window from 32,768
to 98,304 tokens while retaining the existing UD-IQ4_XS weights, shared-Q8 MTP
head, two-token speculative limit, and direct on-demand PLE reads.

Qwen now uses `q4_0` for both K and V cache. Nemotron is capped at 65,536
tokens with a 2 GiB FP8 KV reserve and a 0.35 startup memory ceiling. Prime's
host and OpenShell model catalogs advertise the same 65,536/98,304 limits.

On the deployed 121.69 GiB DGX Spark, both endpoints remained healthy with a
77,034-token Qwen prompt resident and 15.44% memory available. Qwen accepted an
exact 78,000-token prompt, recovered a hidden code at 77,034 tokens, reached
44.76 model-eval tokens/s on a warm 600-token short-context run, and decoded at
29.56 tokens/s after the 78K prompt. The two long prompt tests added six major
page faults in total.
