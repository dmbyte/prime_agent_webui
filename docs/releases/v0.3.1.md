# Prime Agent WebUI v0.3.1 (`.3.1`)

This maintenance release publishes the deployment-focused repository tree.

## Documentation change

- Clarifies that upstream contains only WebUI deployment, operation,
  validation, and service-helper files.
- Keeps production history, conversations, CAD projects, private notes, and
  locally refined agent skills outside version control.
- Removes superseded release-note files and broken references to local-only
  project documentation.

## Runtime

Runtime behavior is unchanged from the preceding build. The release retains the rootless task
broker, credential/model gateway, per-user storage isolation, role-controlled
network modes, service helpers, rollback tooling, and 51-test validation suite.
