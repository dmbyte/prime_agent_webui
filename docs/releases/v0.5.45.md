# Prime Agent WebUI v0.5.45

The memory graph now shows live used and free/available RAM values in GiB when
hovered or keyboard-focused, alongside its existing percentage and sparkline.
The values refresh with the existing one-second telemetry poll. “Free” is
Linux `MemAvailable` (including reclaimable cache), while “Used” is total RAM
minus `MemAvailable`, so the displayed amounts agree with the percentage.

No model, KV cache, or telemetry sampling settings change in this release.
