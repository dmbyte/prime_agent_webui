# Prime Agent WebUI v0.5.24

This release completes the managed-skill runtime integration introduced in
v0.5.23 while retaining lazy loading.

- Embeds the three reviewed managed Python adapters in Prime's immutable kernel
  so tasks can invoke them without writing to the system environment.
- Keeps full BMC and NVIDIA skill instructions lazy: Prime advertises compact
  routing metadata and reads the selected instructions only on demand.
- Lazily imports Playwright only when a BMC browser context is opened and ships
  Playwright only in the `network-operations` image.
- Re-pins all six reproducible OpenShell images and validates managed imports in
  every profile plus a real Chromium launch in `network-operations`.
- Retains the protected catalog of all 366 NVIDIA skills at commit
  `fd9f1466ff8a39178e488981e8b5118709392949`.

Use `v0.5.24` for fresh installation or the WebUI software updater for an
existing Spark deployment.
