# Prime Agent WebUI v0.5.39

v0.5.39 makes protected conversation storage recover automatically after an
abrupt shutdown. Prime temporarily restricts access to its state tree while an
isolated task runs. A normal task restores WebUI access in cleanup, but a power
failure can interrupt that cleanup and make preserved chats appear missing.

The system task broker now runs a constrained ACL recovery helper before every
start. It restores traversal and managed access on conversation, recovery,
project-source, skill, and host task-workspace trees before the WebUI depends on
them. Startup fails visibly if recovery fails instead of accepting tasks with a
silently empty conversation catalog.

The observed recovery preserved all stored transcripts. After repairing the
interrupted ACL, the live owner-scoped API again returned 40 chats and 2
projects. Durable authenticated browser sessions remain intentional, so a valid
saved session can survive a host reboot without asking the user to log in again.
