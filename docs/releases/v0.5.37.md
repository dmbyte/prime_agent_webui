# Prime Agent WebUI v0.5.37

v0.5.37 completes the Prime 0.9.5 OpenShell alignment started in v0.5.36 by
installing and import-verifying all eleven bundled Python-backed Prime skills in
the immutable kernel environment.

The live canary showed why this is required: Prime exposed `agent_message` in
the kernel namespace as unavailable because the custom pre-provisioned kernel
contained `prime-agent-runtime` but not the bundled skill packages. That forced
the model into failed import and unsupported-tool recovery paths even though
the task policy used the correct API.

The rebuilt images now include `agent-message`, `agent-observe`, `attach-image`,
`compact`, `edit`, `goal`, `linear`, `notion`, `refine`, `rlm-heartbeat`, and
`websearch`. Image construction fails unless every corresponding Python module
imports successfully. All six corrected ARM64 profile IDs are pinned exactly.
