# Prime Agent WebUI v0.5.42

This release repairs tasks that end immediately after Prime sends invalid Python
to `ipython`. The observed cell mixed explanatory prose into Python, causing a
`SyntaxError` before any check ran. The WebUI previously labeled that unanswered
turn completed.

If the final tool failure is a Python syntax, indentation, or tab error and
Prime ends without an answer, the dashboard now queues one corrective turn in
the same session. It asks Prime to retry with a short code-only cell and finish
the original request. If the correction cannot start or Prime still produces no
final answer, the task is marked failed and the submitted prompt remains
available. Other tool errors are not automatically retried.

The managed workspace policy also instructs Prime to keep Python cells
code-only and to report a clear result after tool errors.
