# Prime Agent WebUI v0.5.4

This patch release keeps the OpenShell-based DGX Spark runtime and local model
stack: Nemotron 3.5 Lightning as the default local model and Qwen 3.8
Flash-Next as the local specialist.

## Highlights

- Keeps the OpenShell task launcher fix from v0.5.3 so sandbox creation cannot
  consume the initial Prime RPC messages intended for the task exec.
- Updates the WebUI updater so future updates install the privileged runner
  launcher into `/usr/local/libexec/prime-runner-launch`.
- Keeps the Nemotron co-resident memory target at `GPU_MEMORY_UTILIZATION=0.38`
  with the explicit 4 GiB KV-cache cap and three-token DSpark speculative
  configuration.
- Keeps the visible boxed `...` sidebar chat actions and active-chat
  **Add to project** / **Move project** button.

## Upgrade notes

Use `v0.5.4` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
update path so the live dashboard files and privileged runner launcher both
match this tag. Model services do not need to restart unless Nemotron is still
using the older `GPU_MEMORY_UTILIZATION=0.48` setting.

Qwen 3.8 is still the only shipped local Qwen runtime for this release.
