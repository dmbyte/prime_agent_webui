# Prime Agent WebUI v0.5.11

This patch release makes migrated home-backed task workspaces readable from the
host user account.

## Changes

- Applies WebUI-owner and `prime-web` ACLs recursively to
  `~/prime-agent/tasks/USER/` after migrating existing workspace files.
- Preserves default ACLs on task workspace directories so future task outputs
  remain visible from the host.
- Retains the v0.5.10 workspace-volume success fix and the v0.5.9 workspace
  layout.

## Validation

`scripts/validate-release.sh` passed with 97 tests.

## Upgrade

Use `v0.5.11` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
