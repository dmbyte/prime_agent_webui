# Prime Agent WebUI v0.5.41

This release fixes slow or failed chat refreshes after tasks have produced large
runtime logs. The dashboard previously sent every retained log line with each
`/api/state` and `/api/tasks` poll. On the affected Spark, four finished tasks
made each response about 9 MB; timed-out writes appeared in the API journal.

Task refreshes now include at most 32 recent log entries and 32 KiB of log
text per task. The activity panel labels this as a preview. **Complete output…**
continues to read the full owner-scoped, redacted log through its dedicated
chunk endpoint, and the download link remains available.
