# Prime Agent WebUI v0.5.1

This patch release keeps the OpenShell-based DGX Spark runtime and local model
stack from v0.5.0: Nemotron 3.5 Lightning as the default local model and Qwen
3.8 Flash-Next as the local specialist.

## Highlights

- Adds a visible boxed `...` action button beside every conversation in the
  sidebar. Use it to rename, pin, archive, duplicate, export, delete, or add the
  chat to a project.
- Adds an active-chat header button that reads **Add to project** for chats
  outside projects and **Move project** for chats already assigned to a project.
- Keeps right-click conversation actions as a shortcut.
- Hides **Remove from project** when the selected chat is not currently in a
  project.
- Adds regression coverage for the visible chat-project action path.

## Upgrade notes

Use `v0.5.1` for fresh clones and manual upgrades. On DGX Spark, this is a
static WebUI update on top of the v0.5.0 OpenShell runtime; model services do
not need to restart.

Qwen 3.8 is still the only shipped local Qwen runtime for this release.
