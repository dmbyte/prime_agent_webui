# Prime Agent WebUI 0.2.0

This is the first portable installation release. It packages the accumulated
private-LAN WebUI, security, multi-user, provider, usage, update, and interactive
task work behind a single documented install path.

## Highlights

- Complete non-root installer for current Ubuntu/Debian, RHEL-family, and
  SLES/openSUSE systemd hosts
- Private-CA HTTPS, dedicated WebUI authentication, hardened user services, and
  post-install health/authentication checks
- Conversation history, immediate prompt echo, live task progress, native
  steering/follow-up/stop, uploads, provider configuration, model/effort control,
  usage and spend summaries, and Spark telemetry
- Local administrators, power users, and users with recoverable data management
- Immutable release-aware WebUI and Prime Agent update checks
- Synthetic screenshot and comprehensive installation/operations/security README
- Release validator covering 39 Python tests plus shell, Python, and JavaScript
  syntax and required artifacts

## Rootless-container status

Policy enforcement and a hardened Podman runner candidate are included, but the
feature remains off. Do not enable `PRIME_TASK_CONTAINER_IMAGE=1` in production
until the credential gateway, dedicated service identity, per-user migration,
remaining profile images, network enforcement, resource/recovery tests, and an
end-to-end canary are complete.

## Upgrade

Back up `~/prime-dgx-agent`, `~/.prime/agent`, `~/.config/prime-agent`, and the
Nginx configuration/TLS material. Then select tag `v0.2.0` and follow the manual
upgrade instructions in README.md, or use the authenticated administrator update
control once this release is detected.
