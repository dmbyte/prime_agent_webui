# Prime Agent WebUI v0.5.2

This patch release keeps the OpenShell-based DGX Spark runtime and local model
stack from v0.5.0/v0.5.1: Nemotron 3.5 Lightning as the default local model and
Qwen 3.8 Flash-Next as the local specialist.

## Highlights

- Keeps the visible boxed `...` action button beside every sidebar
  conversation.
- Keeps the active-chat **Add to project** / **Move project** header button.
- Fixes the WebUI update path so the shared OpenShell task helper is copied into
  the live dashboard directory before the API is restarted.
- Adds regression coverage for the updater helper copy.

## Upgrade notes

Use `v0.5.2` for fresh clones and manual upgrades. On DGX Spark, this is a
WebUI/API packaging update on top of the same OpenShell runtime; model services
do not need to restart.

Qwen 3.8 is still the only shipped local Qwen runtime for this release.
