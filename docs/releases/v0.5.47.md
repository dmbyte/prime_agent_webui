# Prime Agent WebUI v0.5.47

This release publishes the OpenShell 0.1.2 migration and accumulated task,
administration, skill, and browser-console repairs.

- Qwen owns code generation across all profiles. Coding requests and
  Development/Network operations tasks route to Qwen, coding follow-ups retain
  it, and disabled Qwen produces a visible blocker. Nemotron's managed policy
  limits it to orchestration and simple inspection/delegation cells. Admin
  routing explains precedence; [routing documentation](../model-routing.md)
  includes the default rules and limits.
- The managed HTML5 KVM adapter supports persistent owner-scoped sessions,
  iframe/control discovery, PNG/JPEG captures, safe same-host HTTPS upgrades,
  and session reuse. Console keyboard/text is blocked on login pages until a
  visible graphical surface is focused. Live vendor-console compatibility still
  requires validation; direct IPMI/SOL is not transported by the HTTP gateway.
- Task model/network listeners tolerate rejected or aborted accepts without
  dropping the listener. BMC runtime guidance identifies exact APIs and transport
  boundaries instead of reporting misleading profile-permission errors.
- Long-running chats retain their history and progress. Job logs attach to the
  appropriate conversation turns; tool input/log redaction covers credentials.
  Admin gets a wider workspace and reviewed orphan-sandbox cleanup, project skill
  inventory and wrapping, and clearer update blockers/status.
- Installer/updater paths rebuild all six pinned Prime 0.9.5 images, refresh
  managed skills and policy, and preserve existing storage ACL access.

Validation: 185 regression tests passed locally and on Spark, direct browser and
OpenShell broker fixtures passed, and two consecutive real Qwen-driven synthetic
KVM tasks completed with exactly one verified login and keypress per run, valid
images, session reuse/cleanup, final reports, and no unexpected tool exceptions.
These synthetic tests do not prove successful live iLO authentication or boot.
No real BMC reset or boot action was part of this validation.

Follow the updated [installation and upgrade guide](../../README.md). A WebUI
file copy alone is insufficient: existing Spark installations must also apply
the OpenShell runtime update. Production-local notes and workspaces are excluded
from the distributable tree; existing history is not rewritten.
