# Prime Agent WebUI v0.5.14

This release removes frequent automatic logouts by making WebUI login sessions
long-lived and durable across service restarts.

## Changes

- Extends the idle session window from 30 minutes to 30 days.
- Extends the absolute session lifetime from 12 hours to 180 days.
- Stores active sessions in `~/.config/prime-agent/web-sessions.json` with
  owner-only mode-0600 permissions.
- Restores valid sessions after authentication-service and WebUI updates.
- Persists activity at most once every five minutes to avoid excess disk writes.
- Keeps explicit sign-out, password rotation, administrator revocation, account
  disablement/deletion, idle expiry, and absolute expiry effective.
- Restarts the authentication service during WebUI updates so authentication
  changes are actually applied.

## Upgrade note

The v0.5.14 deployment restarts the old in-memory authentication service once.
You may need to sign in one final time; that new session will then survive later
service restarts and updates.

## Validation

`scripts/validate-release.sh` passed with 104 tests.

## Upgrade

Use `v0.5.14` for fresh clones and manual upgrades. On DGX Spark, run the WebUI
software update from Settings or the installed `~/prime-update/update-webui.sh`
helper.
