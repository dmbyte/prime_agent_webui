# Prime Agent WebUI v0.5.33

v0.5.33 fixes the BMC browser failure that could appear as either a crashpad
database error, an OpenShell task runtime exit, or a task stuck after entering
Prime's IPython tool.

The generated OpenShell policy now grants `/dev/urandom`, `/dev/random`, and
`/dev/shm` when each sandbox is created. Chromium's NSS/TLS runtime requires
those resources, and Landlock confinement cannot be widened after sandbox
startup. `prime-bmc-headless-browser` 1.2.0 also runs each Playwright worker
behind a private per-task Unix-socket broker started before Prime, avoiding the
persistent kernel's child-process state while retaining bounded cleanup and a
private diagnostic log.

A real Prime task through the WebUI API opened three independent browser
sessions in the corrected OpenShell policy. All were ready in under 0.5 seconds;
the middle session navigated read-only to the actual BMC and received HTTP 200.
No credentials, clicks, or state-changing actions were used.

All six normalized ARM64 OpenShell images are pinned by exact immutable ID.
