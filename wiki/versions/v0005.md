# Version v0005 — Prime as long-run capability core

- Date: 2026-08-23
- Status at capture: current
- Previous version: `v0004`

## State captured

The v0004 use cases, model tiers, and trading safeguards remain in force. The
framework topology changes:

- Prime Agent is the core reasoning and orchestration framework.
- Nemotron is the fast parent; Qwen3.6 is the local multimodal specialist;
  GPT-5.6 Sol is the gated frontier specialist.
- Prime's Continual Harness may propose durable improvements, but promotion
  requires frozen regression tests, review, rollback, and no permission expansion.
- Hermes is optional as a replaceable messaging/personal-assistant gateway.
- Financial execution remains outside all agent frameworks.

## Validation evidence

The decision uses the Prime/Hermes capabilities already verified from their
current official repositories. No runtime A/B evaluation has been performed.

## Restoration notes

To restore v0004 conceptually, supersede ADR-0005 and return Hermes to the core
role in a new version. Do not edit earlier snapshots.

## Known gaps

- Frozen cross-domain evaluation tasks do not yet exist.
- Prime, model routing, gateways, and domain tools are not installed.
- Continual-improvement review and promotion automation is undefined.
