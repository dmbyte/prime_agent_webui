# v0061 — Restore collapsible provider Usage summaries

Date: 2026-08-25

The Usage tab once again groups every configured model under its provider. Each
provider is collapsed by default and displays rolled-up tokens and recorded spend
for Today and Last 30 days. Expanding a provider reveals its individual model
rows with the same two accounting windows. Open providers remain open across the
dashboard's periodic refreshes.

This restores the behavior required by ADR-0020 after the native WebUI rewrite
had regressed to a flat model list. JavaScript syntax, all 14 local dashboard/
auth/security tests, whitespace checks, installed asset markers, dashboard
service state, and the private HTTPS authentication boundary passed. The prior
source and installed assets are preserved in the root-only checksummed backup
`/var/backups/prime-usage-v0061-20260825T174000-0500`. This snapshot is
immutable.
