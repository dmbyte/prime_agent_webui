# v0044 — Private dashboard file uploads

Date: 2026-08-24

The conversation workspace now accepts file selection and drag-and-drop uploads.
The API streams files into a private date-partitioned folder, caps individual
files at 100 MiB and total storage at 2 GiB, normalizes names, adds random stored
prefixes, and calculates SHA-256. The interface displays each uploaded file with
a **Copy path** action so the operator can paste the exact Spark path into the
intended Prime prompt.

Uploads do not emit attach commands, send agent messages, resume conversations,
or interrupt work. PAM, private-source ACLs, origin checks, and loopback API
binding remain in force. Rollback restores the v0043 dashboard/API/Nginx files;
uploaded data is retained for separate review. Syntax checks passed. A live
11-byte upload produced the expected size and SHA-256 in 0700/0600 storage, an
unapproved origin returned 403, unauthenticated HTTPS returned 401, the loaded
Nginx configuration contained both streaming directives, both dashboard services
were active, and the full Prime validation gate passed. The temporary test file
was removed. This snapshot is immutable.
