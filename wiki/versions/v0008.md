# v0008 — Private Prime browser interface commissioned

Date: 2026-08-23

Installed Ubuntu ARM64 ttyd 1.7.4 and commissioned `prime-web.service` as a
user-level browser terminal for Prime. It binds only to 127.0.0.1:7681, checks
WebSocket origin, permits at most two clients, and launches `prime-dgx` in the
controlled workspace. The package-created generic system ttyd service is
disabled.

The interface returned HTTP 200, its service is boot-enabled and active, and the
expanded acceptance gate passed both model health checks, all private-binding
checks, browser health, and the 20 GiB available-memory floor. Users authenticate
with their existing SSH key by forwarding local port 7681 and opening
`http://127.0.0.1:7681` locally.
The tunnel was started on the commissioning Mac and the local URL returned HTTP
200; the tunnel itself is intentionally not a boot-persistent service.

Rollback: disable and stop `prime-web.service`; the terminal Prime interface and
model services are independent. This snapshot is immutable.
