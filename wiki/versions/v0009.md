# v0009 — PAM-authenticated Prime browser interface

Date: 2026-08-23

Added Nginx 1.24 and Ubuntu's `libnginx-mod-http-auth-pam` 1.5.5 in front of the
ttyd browser backend. Nginx listens only on 127.0.0.1:8443, requires PAM through
a dedicated policy, proxies WebSockets to ttyd on loopback, and encrypts the
login with a self-signed TLS certificate. Nginx was not added to `shadow`.

The old client tunnel to unauthenticated backend port 7681 was stopped and
replaced by an 8443 tunnel. Remote and local requests without credentials return
401 with the correct authentication realm. Nginx configuration, both services,
private bindings, model health, and memory headroom passed. Positive login must
be confirmed by the user because no password was shared or stored.

Rollback removes the Nginx site and PAM policy and can restore the v0008
SSH-only tunnel. This snapshot is immutable.
