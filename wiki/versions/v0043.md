# v0043 — Nemotron 81,920-token context

Date: 2026-08-24

Nemotron's per-request context limit increased from 65,536 to 81,920 tokens while
its FP8 KV cache remained fixed at 12 GiB. Prime's model registry now advertises
the matching limit. This is a 25% context increase with no intentional increase
in reserved model memory.

Before the change, Linux reported 38.7 GiB available out of 121.7 GiB (31.8%).
After restart and a warm generation, it reported 39.1 GiB (32.15%), exceeding
the 24.3 GiB (20%) requirement. The fixed cache reported 1,884,160 tokens and
23x full-length concurrency. Both model health checks, routing, listener
isolation, and the updated 20% validation gate passed. Rollback restores the
v0042 65,536-token Nemotron limit. This snapshot is immutable.
