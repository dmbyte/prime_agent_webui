# Version v0002 — Two-model DGX Spark agent recommendation

- Date: 2026-08-23
- Status at capture: current
- Previous version: `v0001`

## State captured

The workspace still contains no agent implementation. A researched prototype
architecture is now accepted:

- Nemotron 3.5 Lightning 30B-A3B NVFP4 with the DSpark NVFP4 drafter is the fast
  orchestrator and general workhorse.
- Qwen3-Coder-Next in a GB10-tuned NVFP4 checkpoint is the coding, debugging, and
  review specialist. The bootstrap artifact is community-produced and must pass
  local quality and supply-chain gates.
- Two vLLM processes expose separate OpenAI-compatible endpoints behind a small
  deterministic router.
- Initial context caps are 131K for Nemotron and 65K for Qwen, within provisional
  memory envelopes of about 30% and 50% of the 128 GB unified pool.
- Approximately 20% is reserved for the OS, agent tools, runtime workspaces, and
  operational margin.
- The official Nemotron NVFP4 Spark path uses W4A16 Marlin, not native FP4 tensor
  core execution. Performance claims must use measured application metrics.

Full analysis, sources, alternatives, profiles, and test gates are recorded in
`wiki/AGENT_STACK.md`. ADR-0002 records the durable decision.
