# v0033 — Guarded single-task stop control

Date: 2026-08-24

Every active-task tab now includes **Stop task** in its sanitized event view and
read-only live-console view. The browser requires confirmation, and the dashboard
API accepts only strict IDs that are currently active before invoking Prime's
native single-agent stop command. The saved conversation is retained, and neither
other workers nor the Prime supervisor are stopped.

Local tests verified exact command construction and malformed/inactive rejection.
The deployed endpoint rejected a traversal-style ID with HTTP 400, the dashboard
API restarted healthy, and full Spark validation passed. No real running task was
stopped as part of validation. Rollback restores the v0032 API/JavaScript/CSS
assets. This snapshot is immutable.
