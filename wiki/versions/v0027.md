# v0027 — OpenAI API model mapping correction

Date: 2026-08-23

Installed Prime 0.8.0 code confirms that OpenAI API-key authentication uses
provider `openai`, environment variable `OPENAI_API_KEY`, and defaults to model
`gpt-5.4`. The installed `gpt-5.6-sol` entry belongs to `openai-codex` through the
ChatGPT backend and is not enabled by an OpenAI API key.

The dashboard's planned `openai/gpt-5.6-sol` zero-usage placeholder is therefore
semantically incorrect and awaits a separate interface correction. No credential
or runtime configuration changed. This snapshot is immutable.
