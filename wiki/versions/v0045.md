# v0045 — Vented Pi 5 + iUniker INV001 case

Date: 2026-08-24

The repository now contains a parametric, 3D-printable enclosure for Raspberry Pi
5 with the iUniker INV001 PCIe-to-M.2 HAT+, an SSD up to 2280 length, and the
official Active Cooler. Its 107.2 x 71.2 x 42.4 mm shell has staggered bottom
intakes, a large vented lid, rear exhaust rows, primary port openings, recessed
M2.5 stack mounting, and an M3-secured removable lid. A captive printed plunger
operates the Pi's native power button without additional wiring.

The generator exported separate base, lid, and power-button STLs, a colored
exploded GLB, a PNG preview, and a machine-readable validation report. All three
printable meshes are one-body, watertight, winding-consistent, and positive-volume.
The iUniker production envelope remains unverified because no mechanical drawing
is published; the source records its conservative 90 x 56.5 x 25 mm assumption
and requires measurement, a fit prototype, slicer validation, and a thermal test
before treating the enclosure as physically released. ADR-0033 records the
mechanical strategy. This snapshot is immutable.
