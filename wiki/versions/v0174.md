# Version v0174 — Recover chat access after abrupt shutdown

Date: 2026-09-24

## Verified state

- The power failure did not remove Prime data: 58 protected conversation files
  and 35 legacy conversation files remained present.
- Authentication, dashboard, Nginx, model, OpenShell, and broker services were
  active. A valid durable `dbyte` browser session also remained, explaining why
  the browser did not ask for another login.
- The protected agent directory had an ACL mask of `---`, consistent with power
  loss while Prime had temporarily restricted its state tree.
- Manual ACL restoration made the live owner-scoped API return 40 chats and 2
  projects immediately.
- The broker unit now invokes a validated recovery helper before start. It
  restores managed storage and task-workspace ACLs for every safe owner.
- All 119 dashboard tests pass.

## Rollback

Restore v0.5.38 and remove the recovery helper. This preserves conversation data
but requires manual ACL repair if shutdown interrupts a task again.
