# v0042 — Reboot-safe private dashboard startup

Date: 2026-08-24

The reboot failure was isolated to Nginx: both enabled Prime user services came
up through user lingering, while Nginx tested its explicit private-address bind
before `172.16.253.231` had been assigned. Nginx now has a systemd pre-start
check that waits up to 120 seconds for that exact local address before running
its original configuration validation and start sequence.

The repair preserves the existing loopback/private-address listeners, PAM, TLS,
source ACL, and fail-closed behavior. The helper, merged unit, configuration,
listener scope, unauthenticated HTTP response, both user services, and full Prime
validation gate passed. A second physical reboot was not performed as part of
this repair. Rollback removes the Nginx systemd drop-in and address-wait helper,
then reloads systemd and restarts Nginx after the address is present. This
snapshot is immutable.
