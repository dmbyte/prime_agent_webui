# Version v0075 — Live dialogue and steering

Date: 2026-08-26
Supersedes: [v0074](v0074.md)

## State captured

- New user submissions appear immediately with delivery state, including before a
  new Prime session exists.
- Bounded incremental JSON-event processing publishes safe status/tool events,
  elapsed time, and draft answer text in the dialogue while excluding reasoning.
- The composer offers Message, `/steer`, `/follow-up`, and `/stop` during work.
- Steering and follow-up use Prime 0.8.0's supported running-agent `send` command,
  require a valid agent ID, and are restricted to the owning active task.
- The regression suite contains 30 tests, including safe event projection and
  owner-scoped steering.
