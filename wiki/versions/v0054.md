# v0054 — Correct the WebUI static asset installation path

Date: 2026-08-25

The v0052 HTML referenced `/assets/login.js`, `/assets/login.css`, and the native
application assets, but deployment placed those files directly in the web root.
The login form therefore rendered while its Sign in handler never loaded, and no
password attempt reached PAM.

JavaScript and CSS are now installed in `/var/www/prime-agent/assets/`; login
assets return HTTP 200, the login HTML references both expected URLs, and Nginx
validation passes. A tracked installer now makes the HTML/asset split explicit.
No authentication, firewall, model, or data policy changed. This snapshot is
immutable.
