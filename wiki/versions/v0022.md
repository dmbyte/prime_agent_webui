# v0022 — Constrained click-to-resume conversations

Date: 2026-08-23

Conversation rows are now buttons that resume the selected Prime conversation in
the embedded terminal. ttyd accepts URL arguments only into `prime-web-launch`.
That wrapper forwards exactly `--resume` plus a strictly formed ID that maps to an
existing session file; arbitrary or malformed arguments are discarded and launch
a new default conversation instead.

Unit-style tests passed for valid forwarding and arbitrary-argument rejection.
The live browser click returned an active terminal without echoing conversation
content into validation output. Services, private bindings, both models, and the
complete gate passed. Rollback restores v0021 assets/unit and removes the wrapper.
This snapshot is immutable.
