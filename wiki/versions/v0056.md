# v0056 — Replace PAM with dedicated local WebUI authentication

Date: 2026-08-25

The WebUI no longer uses PAM or the Linux account password. Its unprivileged,
loopback-only broker verifies a separate credential stored only as a strict
mode-0600 salted-scrypt record outside the repository. The interactive
`prime-web-password` command creates or rotates that record without echoing the
password or placing it in shell history.

The broker retains secure expiring sessions, CSRF/Origin checks, request and
attempt bounds, constant-time comparisons, and Fail2ban integration. Credential
loading rejects links, wrong ownership, permissive modes, malformed records, and
unexpected KDF parameters. Scrypt derivation is serialized to bound concurrent
memory use. Login fails closed with HTTP 503 until initial setup; the credential
was intentionally not created or handled by automation.

The removed Prime PAM policy and previous broker/unit/login files are preserved
root-only at `/var/backups/prime-local-auth-v0056-20260825T170500-0500`. Six tests,
Python compilation, service/listener checks, Nginx validation, and the
unconfigured-state response pass. This snapshot is immutable.
