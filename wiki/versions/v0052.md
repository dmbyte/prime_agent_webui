# v0052 — Native session-authenticated Prime WebUI

Date: 2026-08-25

The WebUI now uses an isolated PAM broker and secure expiring sessions instead
of Nginx PAM Basic Auth. Nginx is no longer in `shadow`. A dedicated private CA
signs the Spark certificate; clients can download its public certificate from the
Admin tab. The existing private-source Nginx rules remain and no CIDR firewall
policy was added.

Native chat launches supported Prime JSON tasks in separate process groups with
four-task admission, 30-minute limits, stop controls, persisted message polling,
safe Markdown, parallel activity, redacted logs, and a request ledger. ttyd is
retained only as an advanced authenticated console. Chats can be searched,
renamed, pinned, archived, forked, exported, recoverably deleted, and bulk
archived/deleted.

Files now have metadata, explicit prompt selection, safe previews, deletion,
confirmed retention, and unsafe ZIP/TAR traversal/link rejection. Admin shows
service/storage/task state and guarded restarts. A real native Nemotron smoke
test completed in 2.3 seconds and recorded 6,268 tokens. Seven tests and the full
model/listener/session/header/20%-memory gate pass. Positive password entry and
client CA installation remain owner actions. Recovery bundle:
`/var/backups/prime-webui-v0052-20260825T153014-0500`.
