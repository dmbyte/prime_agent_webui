# v0034 — Top activity overlay and provider switches

Date: 2026-08-24

The background activity overlay now opens at the top-right of the browser instead
of the bottom-right, with a top inset on narrow screens. Dragging, resizing,
minimizing, live console, and per-task stop behavior are unchanged.

Parameters now discovers all configured providers, supports provider/model search,
and presents an enable switch for each provider. Saves translate enabled providers
into Prime's native `enabledModels`; the default-model list contains enabled models
only, and the selected default provider cannot be disabled without first choosing
a replacement. The live catalog contained four providers (`openai`,
`openai-codex`, `spark-nemotron`, and `spark-qwen`); the existing three non-Codex
providers remained enabled after a successful no-change save. Local validation,
deployed asset checks, dashboard service health, and full Spark validation passed.
Rollback restores v0033 assets and removes `provider-settings.css`. This snapshot
is immutable.
