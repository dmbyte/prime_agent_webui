# v0064 — Add guarded Prime and WebUI update controls

Date: 2026-08-25

Settings now provides confirmed actions to update Prime Agent and Prime WebUI,
with running/last-result status and duplicate-run protection. Prime updates use
the existing bundled Node runtime and npm's `prime-agent@latest`. WebUI updates
currently require a clean `main` checkout at the known private GitHub remote,
fast-forward to `origin/main` HEAD, validate Python, redeploy tracked assets and
update services, and restart the dashboard API. Release-list/version comparison
is explicitly deferred.

The network-confined dashboard only starts two named one-shot user services; it
does not gain npm/GitHub network access or general command execution. Per-update
locks serialize runs. This version also fixes the clipped Archived label exposed
by narrow sidebar widths and constrains conversation row contents correctly.

All 19 local dashboard/auth/security tests, Python/JavaScript/shell syntax, and
whitespace checks passed. Deployment, one-shot WebUI self-update validation,
service state, and recovery details are recorded in the current-state and
dashboard pages. This snapshot is immutable.
