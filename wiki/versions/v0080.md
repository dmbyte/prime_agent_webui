Date: 2026-08-26
Supersedes: [v0079](v0079.md)

## State captured

- The repository has a comprehensive root README, synthetic WebUI screenshot,
  and a single non-root installation entry point for Debian, Red Hat, and SUSE
  systemd hosts.
- The installer provisions pinned Prime Agent 0.8.0, private TLS, Nginx,
  dedicated authentication, and hardened user services, then verifies telemetry
  and an unauthenticated 401. It neither opens a firewall nor activates rootless
  containers.
- Runtime origins, initial administrator, and repository path are configurable.
  The updater accepts main or immutable release checkouts and runs the full test
  suite before deployment.
- The release validator passes all 39 Python tests plus Python compilation,
  Bash syntax, JavaScript syntax, required-artifact, README-version, and sample-
  image checks.
- Rootless Podman remains a staged candidate. The gateway, dedicated service
  identity, per-user migration, remaining images, network policy, resource and
  recovery tests, and an end-to-end canary are activation gates.
- Git tag `v0.2.0` and GitHub release title `.2` identify this state.

## Recovery

For source rollback, select tag `v0.1.0`, back up current user data and WebUI
configuration, then run that release's tracked installation procedure. The
v0079 root-only Spark recovery artifact remains the operational pre-container
baseline. Never edit this snapshot; record any rollback as a new version.
