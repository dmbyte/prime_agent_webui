# v0018 — Conversation topics and last-chat time

Date: 2026-08-23

Conversation rows now show a short topic derived from the first user message as
the first line, the latest message date/time as the second, and model plus opaque
ID as tertiary metadata. The user explicitly approved showing sanitized topic
text to authenticated LAN/VPN dashboard users.

Topics are normalized, capped at 96 characters, replaced with `Sensitive
conversation` when credential-like patterns are found, and inserted with DOM
`textContent`. Full prompts, summaries, and assistant messages remain excluded.

All 40 returned conversations had topics and last-chat timestamps, the maximum
topic length was 96, browser ordering passed without echoing topics into test
output, and both model/private-access gates passed. Rollback restores v0017 API
and JavaScript assets. This snapshot is immutable.
