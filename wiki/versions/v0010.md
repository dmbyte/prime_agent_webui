# v0010 — Public exposure assessment

Date: 2026-08-23

The Spark has RFC1918 address 172.16.253.231/24 and routes through
172.16.253.1; its observed public address was 47.187.248.92. It is behind NAT,
UFW is inactive, and no Cloudflare Tunnel or Tailscale client is installed.

No public exposure was enabled. Directly forwarding the PAM-protected,
command-capable terminal was rejected as insufficiently protected against
Internet password attacks. The next implementation should use trusted HTTPS and
an identity-aware public edge—preferably Cloudflare Tunnel/Access—while retaining
PAM as defense in depth. A managed domain/hostname and account authorization are
required. This snapshot is immutable.
