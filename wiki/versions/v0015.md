# v0015 — Prime dashboard sidebar

Date: 2026-08-23

Replaced the terminal-only web root with a responsive authenticated dashboard.
The sidebar controls default local model, thinking level, compaction reserve,
and recent context, and renders Today/7-day/All tokenomics and recorded API spend
per provider. The Prime terminal remains embedded under `/terminal/`.

Added a loopback-only Python API service running as `dbyte` with systemd
hardening, strict allowlists, origin checks, and atomic settings writes. Usage is
calculated from Prime's per-call session records and cost fields; local providers
correctly show $0.

Commissioning parsed 34 sessions and 182 calls. The live browser displayed all
panels, 5.4M recorded tokens, $0 local spend, exact settings, and an active
terminal. API tests and the complete gate passed.

Rollback restores v0014 Nginx/ttyd and disables the API. This snapshot is immutable.
