# v0012 — PAM privilege failure diagnosed

Date: 2026-08-23

The repeated browser login prompt was traced to server-side PAM failure. Nginx
logged `Authentication service cannot retrieve authentication info` for `dbyte`,
and Ubuntu's `unix_chkpwd` helper reported the user unknown when called for the
unprivileged `www-data` worker. The password was neither requested nor exposed.

No operational change was made. Adding `www-data` to `shadow` is the conventional
fix but expands the impact of an Nginx compromise to readable password hashes;
it awaits explicit approval. Client-certificate or identity-provider access is
the safer alternative. This snapshot is immutable.
