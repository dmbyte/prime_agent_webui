# v0060 — Make model routing and effort observable and controllable

Date: 2026-08-25

The active Prime conversation header now shows the effective model, effort,
routing mode, and model context. Effort is editable in place and applies to the
next message in that conversation; the chosen value is retained with conversation
metadata after launch.

The WebUI now routes clear image/document, 3D/CAD/manufacturing,
portfolio/trading, and deep-review prompts directly to Qwen when Nemotron is the
default. Explicit Qwen/Nemotron requests override automatic selection, disabled
Qwen produces a visible fallback, and manually selected frontier/default models
remain authoritative. Prime's policy also requires actual Qwen child invocation
for specialist subtasks inside mixed Nemotron work and prohibits merely claiming
delegation.

Four routing regressions were added. All 14 dashboard/auth/security tests, Python
compilation, JavaScript syntax validation, and whitespace checks passed before
deployment. Eleven applicable deployed Python tests, both model health checks,
dashboard service state, HTTPS authentication boundary, installed assets, and
on-host route probes also passed. The protected pre-change Spark backup is
`/var/backups/prime-routing-v0060-20260825T173500-0500`. This snapshot is
immutable.
