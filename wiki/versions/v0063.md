# v0063 — Add a persistent resizable sidebar

Date: 2026-08-25

The desktop Prime WebUI sidebar can now be resized by dragging its divider. The
chosen width is constrained to a usable 260–700 px envelope (and at most 65% of
the current viewport) and is retained in browser-local storage. Double-clicking
the divider restores the 370 px default.

The divider is an accessible separator with current/min/max values. Left/Right
resize by 20 px; Home and End select the minimum and maximum. It disappears below
the existing 850 px mobile breakpoint, preserving the stacked layout.

dashboard service state, installed asset markers, and the private HTTPS boundary
passed. The prior source and installed HTML/JavaScript/CSS are preserved in the
root-only checksummed backup
`/var/backups/prime-sidebar-v0063-20260825T174200-0500`. This snapshot is
immutable.
