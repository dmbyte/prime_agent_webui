# v0031 — Background activity overlay

Date: 2026-08-24

The dashboard header now includes a background-activity icon and task-count badge.
It opens a draggable, natively resizable, minimizable overlay. Parallel working
Prime sessions become tabs with model/status metadata and a timestamped event feed.

The feed includes task receipt, tool name/start/completion, response-update events,
and token progress. It excludes full prompts, assistant/thinking text, tool input
and output, status summaries, and credentials. The live API returned one task and
14 sanitized events; browser open/tab/minimize checks and full Spark validation
passed. Rollback restores v0030 assets/API and removes `activity.css`. This
snapshot is immutable.
