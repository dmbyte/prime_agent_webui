# v0029 — Automatic Usage model discovery

Date: 2026-08-24

The dashboard now discovers models from Prime's authenticated live catalog,
caches successful results for 60 seconds, and combines them with custom/planned
and recorded models. Usage continues refreshing every 30 seconds, so provider
login and catalog changes no longer require manual list edits.

The post-ChatGPT-login catalog contains 13 OpenAI Codex models and 16 models total,
including GPT-5.6 Sol, direct OpenAI GPT-5.4, Nemotron, and Qwen. A stream issue
was corrected because Prime emits the model table on stderr. API and live-browser
checks showed all four provider families; both local model gates remain healthy.

Rollback restores v0028 dashboard API. This snapshot is immutable.
