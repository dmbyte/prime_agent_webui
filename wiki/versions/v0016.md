# v0016 — Session-first dashboard and Spark monitor

Date: 2026-08-23

The dashboard now opens to a metadata-only Sessions list with a New Session
control. It lists up to 40 recently modified sessions using only modified time,
model, opaque ID prefix, and size. Prompt, summary, first-message, and message
content are excluded from the API and UI.

A compact two-second monitor shows CPU/GPU/memory utilization, maximum ACPI CPU
temperature, GPU temperature, maximum NVMe system temperature, and GPU board
power. The live browser showed all seven metrics, Sessions as the active default,
36 session rows, New Session, and an active terminal. Both inference services and
the complete validation gate passed.

Saved-session resume is intentionally deferred: ttyd URL arguments were rejected
because they permit browser-controlled process arguments. A potential OpenAI API
credential was discovered in plaintext session history; it is not reproduced here
or exposed by the UI and must be revoked/rotated.

Rollback restores the v0015 dashboard assets and API, then restarts
`prime-dashboard-api.service`. This snapshot is immutable.
