# Version v0003 — Prime Agent framework selection

- Date: 2026-08-23
- Status at capture: current
- Previous version: `v0002`

## State captured

The v0002 model and vLLM recommendation remains in force. Prime Agent is now the
recommended prototype agent framework:

- Nemotron is the default parent agent.
- Qwen3-Coder-Next is selected explicitly for specialist RLM children.
- Project instructions provide deterministic escalation triggers.
- Prime's persistent sessions, goals, background work, and Continual Harness are
  used only with reviewed, reversible configuration changes.
- Hermes is retained as the alternative when omnichannel personal assistance,
  scheduled delivery, or user-profile memory outweighs coding/research focus.
- No framework has been installed or benchmarked in the workspace.

## Validation evidence

Current official project documentation was reviewed for local vLLM compatibility,
subagent model selection, multi-model behavior, persistence, skills/memory, and
security boundaries. The recommendation remains gated on a representative local
A/B benchmark.

## Restoration notes

To return conceptually to v0002, supersede ADR-0003, remove Prime from the current
architecture, and restore framework status to undecided in a new snapshot. Do not
edit an older snapshot.

## Known gaps

- Prime/Nemotron and Prime/Qwen protocol compatibility is untested.
- Routing prompts, safety policy, tool schema, and benchmark tasks are undefined.
