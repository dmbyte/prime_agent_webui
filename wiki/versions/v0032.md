# v0032 — Read-only live task console

Date: 2026-08-24

Active-task tabs now offer an optional live Prime console. It attaches lazily to
the selected running session and shows the real terminal state inside the floating
overlay. The overlay console is read-only and can switch back to the sanitized
event feed; the primary terminal remains interactive.

The browser launcher accepts only exact, validated `--attach ID` requests for an
existing session, and continues to discard arbitrary arguments. Only one overlay
console is attached at a time, keeping it within ttyd's two-client limit alongside
the primary terminal. Valid and invalid launcher cases passed local stub tests; a
live browser attach and return-to-feed check passed before the final read-only
presentation adjustment. The deployed Spark validation gate passes. Rollback
restores v0031 dashboard/launcher assets and removes `live-console.css`. This
snapshot is immutable.
