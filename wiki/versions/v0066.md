# v0066 — Add isolated WebUI user administration

Date: 2026-08-25

The Admin tab now manages local WebUI users: add, change role/state, reset
password, delete server cache, and delete account. `dbyte` is the initial admin.
Legacy chats/uploads belong to `dbyte`; new chats, files, tasks, logs, usage, and
metadata are isolated by authenticated owner.

Password storage remains salted scrypt with strict owner-only files. Existing
version-1 credentials migrate atomically on the first management change. Resets,
role/state changes, and deletion revoke the affected user's sessions. Nginx passes
the broker-verified username/role to the API; client-supplied identity headers are
replaced. Admin/system mutations require the admin role.

Deleting cache or an account moves owned chats, uploads, metadata, and known task
logs into private per-user recovery storage. The initial admin and last enabled
administrator are protected. All 24 local tests and syntax/whitespace checks
passed before deployment. This snapshot is immutable.

The pre-change single-user state is preserved root-only at
`/var/backups/prime-users-v0066-20260825T180700-0500`.
